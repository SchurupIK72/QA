# Инструкции для Copilot - Общие правила документации

Используй эти инструкции при работе с любыми файлами в проекте QA.

## Язык
- Документация: **русский язык**
- Код и комментарии: **английский язык**
- Названия файлов: **английский (kebab-case)**

## Форматы файлов
- Чек-листы: CSV
- Баг-репорты: CSV
- Тестовые данные: JSON
- Документация: Markdown
- Тесты: Python (pytest + playwright)

## Шаблоны
- Баг-репорты: `/templates/bug-report-template.csv`
- Чек-листы: `/templates/checklist-regression-template.csv`

## Именование файлов
- Чек-листы: `Checklist-Regression-{ProjectName}.csv`
- Баг-репорты: `BUG-REPORT-{ProjectName}.csv`
- Тестовые данные: `{feature}-test-data.json`
- Тесты: `test_{feature}.py`

## Статусы проверок
- `PASSED` - Проверка пройдена
- `FAILED` - Найден баг
- `SKIPPED` - Пропущено
- `NOT STARTED` - Не начато

## Приоритеты багов
- `Critical` - Блокирует работу
- `High` - Серьёзное влияние
- `Medium` - Умеренное влияние
- `Low` - Минимальное влияние

## Серьёзность багов
- `Blocker` - Приложение не работает
- `Critical` - Критическая функция сломана
- `Major` - Основная функция работает неправильно
- `Minor` - Незначительная проблема
- `Trivial` - Косметический дефект
